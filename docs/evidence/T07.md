# T07 room persistence and protocol gate

T06 merged in [PR #27](https://github.com/jfang88/PandemicGame/pull/27). T07 is in review.

The shared package validates v1 command envelopes and room mutation request shapes, builds structured API errors, and projects rooms into explicit member-visible snapshots. Room and command UUIDs are normalized to lowercase. Firebase-style UIDs retain their original spelling and case. Same-owner create retries return the current room version. Other callers receive a conflict or membership denial as appropriate.

## Acceptance evidence

| Gate | Verified behavior |
| --- | --- |
| P06 persistence slice | Workerd evicts a SQLite-backed room during a discard pause. The recreated instance reads byte-identical game JSON, including the hidden decks, RNG and continuation. Both members receive the same public snapshot. |
| S05 projection slice | Unit tests inject extra fields at the room, member, game, player, cube and event levels. The projection excludes them and keeps the latest 30 events. The Worker integration confirms internal decks, RNG, draw count and invite hash are absent from the HTTP response. |
| Version and request validation | Unsupported command versions produce a distinct schema result. Unsupported SQLite metadata and room versions fail without rewriting data. Nonmembers receive generic denial. Workerd rejects malformed, oversized streamed and wrong-content-type bodies and owner spoofing. |
| SQLite and identity | Concurrent same-owner retries create one room. A SQL-shaped opaque UID round-trips exactly and case changes do not grant access. |
| O01 | The local-test Worker serves the built SPA on a navigation deep link and JSON 404 for missing API paths. |
| Local identity isolation | The local-test header works on loopback. The normal Worker and a non-loopback request reject it. |

Local results on Node 24.22.1 with Vitest 4.1.12 and Cloudflare Vitest plugin 1.6.0 include 180 unit tests and six workerd integration tests. The integration script builds the web assets before the suite. Lint, workspace typechecks and build-kit link/spec validation are part of the PR checks. [Cloudflare Durable Object eviction tests](https://developers.cloudflare.com/durable-objects/examples/testing-with-durable-objects/#testing-eviction)

T07 installs the initial v1 schema. Later migrations, atomic command receipts and events, realtime, retention enforcement and Firebase verification have separate tasks. The internal snapshot writer has no client route. T08 must combine state, events and receipts in one command transaction.
