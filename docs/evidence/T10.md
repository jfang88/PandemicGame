# T10 realtime gate

T09 merged in [PR #31](https://github.com/jfang88/PandemicGame/pull/31). T10 is in review.

Room ticket issuance requires membership and an exact configured origin. The SQLite ticket stores a hash, origin, UID and deadlines. Upgrade checks these fields and consumes the ticket in one transaction. Hibernating sockets serialize their UID, expiry and connection order. The room rereads membership and the latest public snapshot before sending post-commit updates.

Durable Object alarms close idle expired sessions and remove expired tickets. The room caps live sockets at two per member and eight per room. A third connection for a member replaces the oldest. Incoming gameplay frames are rejected. [Cloudflare WebSocket hibernation](https://developers.cloudflare.com/durable-objects/best-practices/websockets/) · [Cloudflare alarms](https://developers.cloudflare.com/durable-objects/api/alarms/)
