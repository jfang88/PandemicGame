# T09 private lobby gate

T08 merged in [PR #30](https://github.com/jfang88/PandemicGame/pull/30). T09 merged in [PR #31](https://github.com/jfang88/PandemicGame/pull/31).

Rooms issue 128-bit random invites. The active invite is stored as a SHA-256 hash. The raw secret is returned only to the current owner on rotation or an exact retry of that rotation. An old receipt never reactivates an invite. The last leave expires the lobby and erases its stored invite secrets while retaining the leave receipt.

Admission fills the lowest vacant seat and preserves occupied seats. The SQLite transaction enforces a maximum of four members and unique selected roles. Joining and leaving clear readiness for the remaining roster. The lowest occupied seat takes ownership when the owner leaves. A ready roster starts once with a server-generated seed, then membership freezes.

| Gate | Workerd evidence |
| --- | --- |
| P07 | Concurrent requests by one identity allocate one seat. Two contenders for the final seat yield one acceptance. Concurrent selection of the same role yields one accepted revision and a role conflict on a fresh retry. |
| P08 | Owner departure transfers ownership and clears readiness. A leave/start race commits one mutation. Once started, late joins and leave commands fail. An exact start retry after eviction returns the original acceptance. |
| S02 | Nonmembers cannot read rooms or rotate invites. A departed member receives only its exact leave receipt, with no snapshot, even after eviction. The normal Worker rejects the local identity header. |
| S08 | Rotation invalidates the previous invite. Replaying an earlier rotation returns its private receipt without changing the current invite. Public events and snapshots exclude invite secrets and hashes. |
| Compatibility | Storage migration preserves T08 command receipts and their original acceptance after eviction. |

The suite also covers missing rooms without logical creation, readiness and owner-only start, cross-route command ID reuse, and the expired empty lobby. Independent review caught the need to erase raw invite receipts at abandonment. The fix and its direct SQLite assertion are included. Real Firebase authentication and disconnect handling are later gates.

Local verification passed with 180 unit tests and 22 workerd integration tests, lint, workspace typechecks, the web build, and the Worker dry build. The normal bundle excludes local identity and fault controls.
