## Boundary and behavior

`applyCommand(state, actorId, {type, payload})` is a pure internal engine function.
It accepts MOVE, DIRECT_FLIGHT, CHARTER_FLIGHT, SHUTTLE, TREAT, BUILD_CENTER and PASS.
The future protocol adapter supplies the authenticated actor separately and strips
room-level envelope fields after validating them. Unknown engine properties/types
are rejected. Input state is trusted internal engine data, not client-supplied JSON.

Results are a discriminated union: `{ok:true,state,events}` or
`{ok:false,state,events:[],error}`. Rejection returns the exact original state reference.
All legality and card checks precede candidate construction. Accepted actions cost
one action, conserve cards/cubes and leave RNG unchanged. Readonly unchanged branches
may be structurally shared; consumers must not mutate engine snapshots.

Public events are explicitly constructed from public facts: card discard, movement,
treatment, construction or pass, then ACTION_SPENT and (when needed) PHASE_CHANGED.
They contain no decks, RNG, input envelope or whole snapshot. Errors use BAD_REQUEST,
WRONG_TURN, WRONG_PHASE, GAME_FINISHED or ILLEGAL_ACTION; the room adapter will map
them to the protocol response. Paid actions prepend the discarded card to playerDiscard.

## Acceptance coverage

- E03: adjacent move, exact cost; self, unknown and nonadjacent destinations rejected.
- E04: direct/charter flights discard only the required owned card; wrong/missing
  cards and self/unknown destinations leave state unchanged; discard ordering frozen.
- E05: shuttle requires both centers, different endpoints and no card cost.
- E06/E07: ordinary uncured treatment removes one; Medic or cured removes all chosen
  color; supply returns exactly; other colors remain. Foreign home colors are treatable.
  Moving a Medic into a cured infected location has no passive effect.
- E08: ordinary construction spends matching card; Builder spends no card even when
  holding it. Existing center and seventh center rejected; sixth accepted for both roles.
- Relevant E23: wrong/unknown actor; non-action and terminal phases; malformed/extra
  payload properties; invalid action budgets. Rejections preserve input bytes, reference
  and RNG and emit no events. Accepted paths use deeply frozen input and exact events.
- Every accepted fixture/action checks structural/card/cube invariants. E02-style
  repeat invocation verifies deterministic state and events.

## Temporary turn boundary

After the fourth action, T03 returns phase DRAW with zero actions, the same active seat,
unchanged decks and RNG. Tests cover this boundary for all seven commands and reject
further actions. T05 must connect the automatic draw/infection resolver before these
intermediate candidates can be persisted or exposed as completed room mutations.
This is not E11 completion, a finished turn engine or a playable game.
