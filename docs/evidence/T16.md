Actual edge counter behavior, hosted load, and Cloudflare CPU metrics for cold and cached Firebase verification require an authorized preview. [Operations runbook](../OPERATIONS.md)

An independent security review identified create retries at the hourly ceiling, command ID mismatches that bypassed the room bucket, raw identity keys, and ticket-bearing invocation logs. The final implementation allows same-ID create retries, charges mismatched command IDs, hashes identity keys, and disables invocation logs in both named environments. The named preview Wrangler dry run resolved both SQLite bindings and both edge limits.
