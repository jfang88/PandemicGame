# T08 atomic command gate

T07 merged in [PR #28](https://github.com/jfang88/PandemicGame/pull/28). T08 merged in [PR #30](https://github.com/jfang88/PandemicGame/pull/30).

The command route validates the wire envelope and hashes its canonical JSON before reading authoritative state. Within one synchronous SQLite transaction, the room checks membership and compatibility, looks up the per-user receipt, compares the expected revision, applies the engine transition and writes the new state, ordered events and receipt. The storage version advances from 1 to 2 while the game snapshot schema stays at 1.

An exact retry returns the original accepted revision with the current public snapshot. Reordering JSON object keys preserves the hash. Card list order remains significant because it affects discard order. A retry creates no new events or writes and skips the delivery hook. A fresh acceptance waits for durable storage before invoking the post-commit hook or acknowledging the client.

| Acceptance | Workerd integration evidence |
| --- | --- |
| P01 | Concurrent requests for the same command produce one fresh acceptance and one duplicate. After another mutation and eviction, a retry still returns the original accepted revision and the latest snapshot. |
| P02 | Changing the payload or expected revision for a used ID returns COMMAND_ID_REUSED. A nonmember cannot probe the receipt, and the same ID is scoped to its submitting member. |
| P03 | Two distinct commands at the same revision produce one acceptance and one STALE_VERSION. Invalid inputs leave all SQL rows unchanged. |
| P04 | Faults after the state write, after the event writes and after the receipt write all roll back the entire transaction. The same command ID then applies once. |
| P05 | A post-commit fault returns a retryable error. The rows survive eviction and the retry recovers the acceptance without a second mutation. |
| P06 | A paused discard, the hidden decks and RNG survive eviction exactly, and the discard resumes from the stored continuation. A v1 SQLite room migrates without recreating the game. |

The runtime suite also verifies that a terminal loss is an accepted command and that the receipt survives game end. Fault controls live in the loopback-only subclass. The normal Worker bundle excludes the test identity header and fault controls.

Local verification covered 180 unit tests, 14 workerd integration tests, workspace typechecks, lint and the Worker dry build. A separate stronger-model reviewer independently ran the runtime suite and found no transaction blockers. T09 adds lobby commands and invite receipts. T10 connects the post-commit hook to realtime delivery.
