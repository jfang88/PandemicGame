# T11 Firebase authentication gate

T10 merged in [PR #32](https://github.com/jfang88/PandemicGame/pull/32). T11 is in review.

The normal Worker verifies Firebase ID tokens with JOSE 6.2.15 and Google Secure Token X.509 certificates. The browser uses Firebase Web SDK 13.2.0 for Google and Microsoft popups, session initialization, sign-out and ID-token refresh. The adapter omits automatic emulator initialization. [Firebase ID token verification](https://firebase.google.com/docs/auth/admin/verify-id-tokens) · [Google popup](https://firebase.google.com/docs/auth/web/google-signin) · [Microsoft popup](https://firebase.google.com/docs/auth/web/microsoft-oauth) · [JOSE](https://github.com/panva/jose)

| Gate | Automated evidence |
| --- | --- |
| S01 / S09 | Workerd signs Firebase-shaped tokens with test-only RSA keys. It rejects forged, malformed, unsigned, wrong-project, expired and algorithm-confused tokens, and validates exact audience, issuer, UID and time claims. |
| S02 | The normal Worker accepts an opaque signed UID for room creation and read. A different UID with the same email cannot read the room or obtain a ticket. The signed expiry binds the ticket lifetime. |
| S05 / S06 | The normal Worker rejects local identity headers and unsigned emulator tokens. Configured web and normal Worker artifact checks exclude signing fixtures, test identities and emulator settings. |
| S10 | Workerd verifies the fixed certificate endpoint, redirect denial, cache lifetime and Age, concurrent fetch deduplication, rotation, unknown-key cooldown, timeout and fail-closed expiry. |
| Popup and invite | Chromium simulates provider outcomes and verifies initialization, popup-blocked and collision recovery, sign-out, safe returns, short-lived invite storage, cleanup, and same-ID refresh retry. A cross-tab UID change prevents the retry. |

Local verification passed with 186 unit tests, 35 workerd integration tests, the Chromium popup smoke, and configured web and normal Worker build inspection. A stronger independent reviewer reran the signed-token workerd suite and found no remaining security blockers.
