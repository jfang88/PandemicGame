# Debug handoff prompt

```text
Diagnose this bounded failure without redesigning the project.
Task ID and acceptance ID: ...
Commit/branch: ...
Expected behavior from spec: ...
Observed behavior: ...
Smallest reproduction and failing command: ...
Seed/command trace if relevant (no credentials): ...
Relevant files/functions: ...
Last two attempted fixes and their results: ...
Sanitized error output: ...

Identify the likely root cause, propose the smallest fix, and specify a
regression test. Do not weaken the expected behavior or introduce a new
service. Distinguish evidence from hypotheses. Return a focused patch
only if enough context is present; otherwise request the exact missing
code/log, not the whole repository.
```
